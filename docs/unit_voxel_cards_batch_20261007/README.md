## 使用方式

打开 index.html 浏览全部角色卡。点击图片可查看原尺寸；卡片下方提供 PNG、原始参考和绘图提示词的独立链接。

- cards/：角色卡 PNG。
- sources/：本次上传的五张原始参考副本，按相同编号保存。
- prompts/：逐角色实际提交给内置 image_gen 的完整提示词。
- manifest.json：角色、原图、参考图、输出和校验值的对应记录。
- verification.json：交付检查结果。

每张含主展示图、正面/背面/侧面、装备或结构拆分和三处细节特写。钢琴师的整台三角钢琴单独展示；人偶修女保留关节与机械分段；蛇尾执钥者保留双腿与独立蛇尾。

## 绘制方式

使用内置 image_gen，未使用外部 API 或 CLI 绘图。每次生成使用三张参考：对应上传原图、既有 archer 角色卡版式，以及 D:\voxel\docs\character_sheet.png 中的游戏体素风格。

原图未展示的背面和连接关系按角色设计合理补全。这些图用于体素建模的视觉设计参考，不是带精确尺寸的工程投影，也不是可直接导入的三维模型。服装、色彩、种族特征与关键道具以原图为依据。
