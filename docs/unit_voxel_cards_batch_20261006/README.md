## 浏览与文件

- index.html：本地图库，可搜索编号、中文标签和英文文件名。
- cards/：七张独立 PNG 角色卡。
- sources/：按相同编号保存的七张原始上传参考图。
- prompts/：每张图实际提交的完整绘图提示词。
- manifest.json：原图、输出、提示词、像素尺寸与校验值的对应清单。
- verification.json：最终文件核验记录。

每张包含左上完整主视图、右上独立装备或结构模块、左下正面/背面/侧面转面，以及右下三处细节特写。

## 生成与建模说明

全部由 Codex 内置 image_gen 逐角色绘制。原画决定角色身份、服装和装备；上一批 archer_voxel_card.png 决定版式和渲染处理；D:\voxel\docs\character_sheet.png 决定游戏体素造型语言。

PNG 保留工具原始输出分辨率。交付为图像建模参考，非 .vox 或三维网格。原画未展示的背面、内侧和连接结构按源设计补全；实际建模时仍需统一网格、关节与绑定。
