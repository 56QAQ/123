## 设计理由

- **仙人掌双枪(绿手枪 4 费)**：能装的浪游 / 巧运 / 清心都是"单体 · 低频"(浪游 / 巧运 = 自己，清心敌我各半)，所以是不带【群攻】的固定值双模【基本】。
  前几批的教训(gen8 / gen11)：浪游 / 巧运开战 9 秒左右就倒下，能改变胜负的是"把保护溅给身边缠斗的前排"——
  这一把给前排披的是【刺甲】：护甲 + 每秒回复，**谁用普攻打它就被扎一下**(状态附带的触发器 `OnHitByNormalAttack` → 攻击者，`source_has_status` 守着，
  状态掉了就不扎；写法照青影的诛影)。敌人那一边是一簇刺(溅射)+ 1 秒眩晕(不溅)：清心的弱体符打物理输出最高的敌人。
  和豌豆荚(绿 2：护盾 + 荚衣减伤 + 眩晕)、荆棘手弩(绿 4：再生 + 定身缴械)、蒲公英(绿 2：闪避)不撞：这一把是"反伤"。牛仔 + 仙人掌：浪游的外观就是荒野牛仔。
- **拳套弹簧枪(红手枪 3 费)**：能装的速射 / 护理 / 清扫 / 巧运里，速射(敌人 · 高频 · 10)和护理(受伤的队友 · 0.7 次/秒 · 172)是主力：
  ①【基本】固定值双模(速射吃满)、③ 冷却 3 秒的放大回复(护理)；② 一拳眩晕(速射卡在 40 级的墙下，控制比伤害值钱)。
  红手枪 / 红手弩已经有泡泡枪(回复 + 护盾)、烟花筒(溅射 + 伤害转治疗)、朝天椒(辣劲 + 燃烧 + 呛咳)，这一把队友那边是【斗魂】(全能吸血 + 攻击)——
  护理奶的那个前排边打边吸血。清扫拿手枪不近战(女仆护身术 0 次)、巧运 +0：fit_remove。
- **磁极双枪(紫手枪 4 费)**：紫 = 红 + 蓝，右手红极、左手蓝极的马蹄磁铁。冲着架盾做(盾，我的盾！→ 自己 + 身边的敌人，需要双模 · 多目标)：
  【群攻 2】正好是"她自己 + 打她的那个敌人"——自己的盾补回来(固定 + 放大)，打她的敌人被磁化(攻速 / 护甲降)、吸到她面前嘲讽 3 秒，
  而且够得着它的队友都改打它(`fish_pull` 本来是追猎"意外渔获"的效果：拉过来 + 嘲讽 + 集火)。护理的药水填充是单体：拿到的是护盾那一边，按测强度 fit_add。
  速射的目标被吸到她自己面前是坏事(39，+1)，标签也不配。和千纸鹤(青 3)、铆钉枪(蓝 2)、共振双铃(黑 3)这几把"给架盾的护盾枪"错开：这一把是"把打她的吸过来、让全队集火"。
- **薄荷手弩(绿手弩 3 费)**：只有浪游 / 清心能装，两只都是"单体 · 低频"：给的东西本场不消退(【清凉】叠层：回复 + 受到的治疗)、溅给身边的队友；
  敌人那边是【呛眼】(造成的伤害降低，也溅给它身边的敌人)。清心的清心符本来就在奶前排，清凉的"受到的治疗"正好放大她自己的符。
  **原名萤火虫手弩(玻璃罐弩托)：和 gen16 同时做的萤火虫瓶(黄法器，玻璃罐 + 软木塞 + 【萤火】回复)撞了概念，机制不变、外观 / 名字 / 投射物改成薄荷**。
  和蒲公英(闪避 + 迷絮减攻)、荆棘(护盾 + 再生 + 荆缚)、珍珠贝(青 4)不撞。
- **心火双刃(红双匕 3 费)**：能装的五只里，狂猎(再来一次：濒死时打身边一圈，727)和舞星(笑给队友 / 泪打敌人，只有双模不会用反、要【基本】)是"多目标"的两只，
  狩胜 / 清扫 / 巧运是单体——这一把冲着前两只：双模【群攻 2】【基本】。核心是 ② 的 `pre_effects` 回复：**狂猎的"再来一次"结算完血量还不够才倒下**，
  心火一跳(回复 120)就能把他从致命的那一刀里拉回来，击杀又重置再来一次；舞星每次普攻给两个队友心火(她吃续航：gen13 的教训)。
  和彩绸双刃(黄 2：喝彩攻击 / 吸血 + 放大伤害)、舞扇(舞星专武)、狼双刃(狂猎专武)错开。
- **蝙蝠双刃(紫双匕 2 费)**：迅游(踢最远的敌人，1132)、清扫(近身的敌人，379)是"对敌人 · 单体 · 数值大"，狩胜 / 巧运是"自己 · 低频"——不带【群攻】的双模，冷却 2 秒：
  敌人那边吸一口血(× 25% 魔法 + 自己回复同样多)+ 超声波眩晕(踢飞的后排 / 贴上来的近战)，自己那边叠【蝠群】(狩胜每次击杀一层，本场不消退)。
  和猩红獠牙(紫 3：暴击放大)、闪电手套(迅游专武)不撞。巧运 +0：fit_remove。

## 适配修正(fit_add / fit_remove)

- 磁极双枪 `fit_add=["node_nurse"]`：护理的药水填充是单体插槽、武器有【群攻 2】(标签对不上)；测出来 49 → 60(54 / 58 级 53% / 33% → 70% / 62%)。
- 拳套弹簧枪 `fit_remove=["node_maid", "node_rogue"]`：清扫拿手枪不近战，女仆护身术一次都不响(fitprobe 0 次；62 → 65 是纯属性)；巧运 39 → 39。
- 蝙蝠双刃 `fit_remove=["node_rogue"]`：巧运 42 → 42。

## 教训

- **并行的批次会撞概念**：gen16 同时做了"萤火虫瓶"(玻璃罐 + 软木塞 + 【萤火】回复)，和我的萤火虫手弩几乎一模一样。
  下一组派活时可以先把每批的"外观关键词"列出来互相看一眼(这一批中途改成了薄荷；r1 的数据不受影响：机制没变)。
- **击退对速射是负的**：把她的目标推开以后，前排和速射自己都要重新索敌、追过去；同样的位置换成 0.8 秒眩晕，44 级 55% → 68%。
- **舞星拿双匕吃的是"每次普攻给几个人"**：心火的减伤 / 回复降一档几乎不动，【群攻 3 → 2】一下少 8 场——调她看【群攻】的数，不看状态的强度。
- **狂猎的"再来一次"结算完血量不够才倒下**：武器给他一口固定回复(`pre_effects` heal)就是一次复活，击杀又重置——这一段很值钱，回复量要压。
- **迅游的胜率是平的**：62 ~ 98 级慢慢往下，搜索在墙上一跳就是几十级；比他要看一条 74 ~ 98 级的同强度曲线。
