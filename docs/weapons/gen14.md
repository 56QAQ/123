## 设计理由

- **翠鳞鞭剑(绿 4 · 对敌人 · 单体【基本】)**：绿单手剑扣得勤的是无我、炽照(高频单体)。已有的同类(金雀细剑 = 暴击叠层、鎏金军刀 = 攻速叠层、
  青藤剑 = 自身攻击 / 生命叠层)都是"给自己叠"，这把是"给敌人叠"：蛇腹剑一鞭抽在目标上、鳞刃扫过它身边的敌人(【溅射】+ `splash_filter: target_allies`，
  只扫目标那边)，目标叠【鳞裂】降护甲(绿色羁绊 4 档还会多叠一层)——追击 / 幻影 / 拔刀连斩这种一轮好几刀的，几下就把护甲撕开，队友的物理伤害也吃。
- **蓝徽骑士剑(蓝 3 · 双模【群攻 3】固定值)**：蓝单手剑的主力是基础大类就是单手剑的架盾(敌我都有、触发数值只有 50 → 固定值)，再加和星(对队友 · 多目标)、
  圣战 / 执剑。已有的刻时剑(超频 + 护盾 / 魔法)、紫藤长剑(回复 / 吸血)、裁誓仪剑(减伤 / 易伤)都不嘲讽：这把的敌人那一边是"举起纹章"——
  通用的 `taunt`(携带者身边 3 米内的敌人只能打携带者)。架盾每次盾破都给自己一面 120 的新盾、把身边的敌人拉到自己身上；和星那一边是护盾 + 法强 / 计时加速。
- **斗牛士剑(红 2 · 双模【群攻 4】)**：红单手剑里只有共歌是多目标(敌我都有)，狩胜 / 守誓是"打自己"。红色羁绊是攻击力 + 普攻伤害，所以队友那边给【斗魂】
  (攻击 + 普攻伤害)、敌人那边给【红布】(护甲 / 魔抗一起降：斗篷一抖，冲上来的人破绽全露)，第二段吃触发数值(回复 / 物理)。
  和沉沦之梦(增幅 / 减免效能)、紫藤长剑(回复 / 吸血 / 减疗)、血宴长剑(单体回复 + 叠层)不撞。
- **苔衣巨剑(绿 3 · ①【基本】固定值双模 ② 双模)**：绿双手剑能装的有无我(基础大类，高频单体)、炽照(高频单体，基础双手剑就 83)、耕植(一场一次 → 自己)、锁芯(多目标)。
  已有的荆棘 / 蚀骨巨剑都是"给敌人叠"的输出，这把是"给自己叠"的续航：每扣一下携带者长一层【苔衣】(本场，减伤 + 回血)，
  耕植的收获时刻(生命首次低于一半)走第二段，一下长满。锁芯(深空之门是多目标插槽)不在这把的路子上——她的金钟 / 雷鸣 / 凝潮 / 涌泉已经够多。
- **沉锚巨剑(蓝 2 · 双模【群攻 3】)**：蓝双手剑的基础大类是圣战(对敌人 · 多目标、卡在 62 级的墙下)，和星对队友 · 多目标。
  一只铁锚：队友那边护盾 + 【锚定】减伤(和星吃护盾)，敌人那边魔法伤害 + 【沉锚】(移速 / 攻速一起拖慢——圣战砸到的一片被锚住，下一锤、圣疗都更从容)。
  和碎岩巨剑(碎甲)、大锤(眩晕)、鲸歌长枪(法强 / 降魔抗)错开。
- **鮟鱇灯杖(蓝 3 · 按阵营分支【基本】【群攻 4】固定值)**：蓝矛能装的五只里，灾星不能装护符(【双模】)、触发器又是敌我都有——只有"不是护符、但按目标阵营分支"
  的武器适配她(玫瑰花束同理)：两段都用 `bullet` + `ally_effect` / `enemy_effect`。队友叠【灯明】(法强)、敌人叠【诱光】(降魔抗)再被咬一口，
  都是叠层(灾星拿蓝色武器时【叠加】状态多叠 1 层)；【基本】让巫术每 2 秒一次的啄击也吃得满，诱光降魔抗正好配他的魔法飞弹。

## 适配修正(fit_add / fit_remove)

- 斗牛士剑 `fit_add=["node_gladiator"]`：狩胜的"我已得胜"是单体插槽(打自己)、武器有【群攻】，标签对不上；实测拿基础单手剑 61 → 66(+5)。
- 鮟鱇灯杖 `fit_add=["node_wizard"]`：巫术的啄击是单体插槽、武器有【群攻】，标签对不上；实测拿基础长枪 49 → 53(+4；搜索里顺带打的 58 级前压 9/18 → 78/120)。
- 蓝徽骑士剑 `fit_remove=["node_paladin"]`：圣战拿基础单手剑 60 → 61，62 级同强度 55% → 55%(+0)。
- 沉锚巨剑 `fit_remove=["node_astronaut"]`：星旅拿基础双手剑 44 → 44(+0)。
- 鮟鱇灯杖 `fit_remove=["node_druid"]`：和星拿长枪 49 → 51，54 级同强度 50% → 50%(+0)——他吃护盾不吃法强叠层(gen12 鲸歌长枪也是护盾那一段起作用)。
- 留着的"适配但不合手"：鮟鱇灯杖的星旅(+2)；蓝徽骑士剑 / 沉锚巨剑的执剑(★2 不带武器就 ≥100，测不出来)。

## 模型

都在 `tools/weapons/gen14_models.gd`，颜色写死(VGrid.hexc)、主色 = 武器颜色，握法 / 尺寸照同大类现有武器，`./run_kits.sh` oob 0。

- 翠鳞鞭剑：七节翠绿的鳞刃串在一根钢索上(节间露出一格银灰的钢索，每节下沿削掉两角 = 倒钩、往上收尖，相邻两节深浅交错，每节刃心一颗发光的翠点)，
  整条刃微微扭成一道 S 形；剑格是一条盘成横档的青蛇(两头往上卷)，蛇头在正中、金眼、两颗白獠牙，剑身从它嘴里吐出来；墨绿皮柄缠金丝，金柄头嵌祖母绿。
- 蓝徽骑士剑：银亮直刃、两面一道发光的蓝色嵌线；银横档两头金色小卷，正中立着一面鸢形的纹章盾(金边、蓝底、银色人字纹、正中一颗发光的蓝宝石，两面都有)；
  藏青皮柄缠银丝，银柄头嵌蓝宝石。
- 斗牛士剑：细长亮钢刺剑、最后几格往一侧勾；金色浅盘护手 + 小横档；红绳缠柄、金柄头；横档一头搭着一角猩红的斗篷，顺着拳头外侧垂下来(一道道褶、下摆金边)。
- 苔衣巨剑：灰绿的古石刃身(又厚又宽、刃口崩着缺口、几道暗色裂缝)，裂缝边长出一团团青苔，刃心一道淡绿荧光的苔脉；方石剑格顶上铺苔、两头抽出小蕨叶、
  底下垂着苔须；老树皮缠柄，柄尾一颗圆润的河石。
- 沉锚巨剑：柄尾是锚环(几颗白色的藤壶)，锚杆就是柄和刃(下段缠着蓝色的缆绳，上段松开绕两圈)，横档是锚杆上的短横杆(两头铁球)；
  锚杆顶上圆圆的锚冠 + 一枚短刺，两条锚臂往两边弯下来，臂尖是刷成蓝色的铲形锚爪(刃口磨亮)，一条臂上挂着一缕海草。

## 教训

- **无我吃续航吃得很凶**：苔衣巨剑首版(本场 15% 减伤 + 每秒 60 回血)让她从 75 一下到 91，86 级同强度把减伤和回血拆开，单留哪一项都还有 +22~32 个百分点——
  "一轮打好几下 + 本场叠层"的武器给她时，叠层的上限要压得比给别人的低(定稿叠 8 层、合计 6.4% 减伤 + 每秒 16)。
- **无我 / 炽照拿高频【基本】武器很容易冒过头**：鞭剑首版 +16 / +11，砍到 20 点、每层护甲 -4 才回到 +8 / +7；84 级(无我)、70 级(炽照)前后同强度都差 30 个百分点，
  看搜索结果时注意墙。
- **灾星只能装"按阵营分支、但不是护符"的武器**：她 2 星起禁的是护符这个结算规则(`forbid_classes: amulet`)，`bullet` / `blade` + `ally_effect` / `enemy_effect` 照样是双模。
- 和星拿长枪不吃法强叠层(+0)，吃护盾(蓝徽 / 沉锚 +10)——和 gen12 的结论一致。
