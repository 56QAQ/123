## 设计理由

- **两把绿法器(只有清心 / 守林能装)**：两只的插槽正好相反——清心的道法自然一场五六次、触发数值只有 10、敌我各半；守林的原初血脉一场 3 次(开局 + 两次本应倒下)、
  只打自己、触发数值 323。所以两把都是不带【群攻】的双模(两只都是单目标)，一把全是固定值(偏清心)，一把按触发数值放大 + 本场叠层(偏守林)，
  也都和杨柳净瓶(绿 3：①【基本】甘露 / 枯萎 ② 放大回复)不撞：
  - **青玉葫芦(绿 2)**：道士的仙丹葫芦。清心符治过的那个队友(连同身边的队友：青雾散开)吃一粒仙丹，最大生命永久 +70、能一直叠；
    弱体符打过的物理输出最高的敌人挨 70 魔法(也散给它身边的敌人)并喝醉(攻击 / 移速降低)。守林开局和每次变身也吃一粒，属性只给生命——
    法强对守林是全套技能的系数，对清心没用，为了让这把偏清心去掉了。
  - **三兽图腾(绿 4)**：狮子 / 蜘蛛 / 蟾蜍三张脸的图腾，正好是守林的三副兽身。他每换一副兽身(本应倒下、只剩 1 血的那一刻)回一口 触发数值 × 40%(开局满血时变成护盾)、
    叠一层本场的【兽魂】(攻击 + 减伤)；清心那一边吃第二段：被治的队友叠兽魂、被弱体的敌人攻速降低。
- **萤火虫瓶(黄 2)**：能装的八只里挑了"多目标"的三只——灭罪(光束每 0.25 秒一次、两三个敌人、触发数值 15)、导向(连锁闪电打完、三个敌人、138)、
  舞星(笑：3.5 个队友、高频；泪打敌人，单边武器会用反)。全部【群攻 3】双模，①② 是【基本】固定值(灭罪的光束扫过的敌人都亮着、各灼一下)，
  ③ 冷却 3 秒放大(导向那一串敌人挨一大群萤火)。舞星吃 ① 的萤火(她拿法器吃续航：玫瑰花束的教训)。和玫瑰花束(红 3 法器)不撞：这把是"标记 + 一直灼"。
- **凤首箜篌(黄 3 弓)**：凤首箜篌改成的长弓，弓腹一侧立着琴柱和五根琴弦。心音(敌我都有)、追猎(威胁目标，贴着我方前排)、屏息(击杀溢出 → 最近的敌人)
  三只都是单目标、低频：不带【群攻】的双模，① 放大的魔法 / 回复 +【溅射】(弦音传开；`splash_filter: target_allies` 只溅给目标那一边)，
  ② 一对 6 秒的状态(队友加攻击 / 法强、敌人减攻速)。和金乌长弓(黄 4：【学习】【暴击】)不撞。
- **青鸾长弓(青 3 弓)**：追猎(威胁目标 150)和和星(自己 + 护星 291，吃护盾)走 ① 放大的双模(物理 / 护盾)；
  真望拿弓时插槽只在她阵亡时响，所以加了 ②【限制：阵亡时】每场一次的涅槃(青鸾浴火)：勇气一响她就原地复活。和逐风短弓 / 青龙长弓的区别就在这一段。
  和星是多目标触发器、武器不带【群攻】：标签对不上，按测强度 fit_add。
- **向日葵步枪(黄 4 步枪)**：能装的六只里，速射(敌人、高频、10)、护理(受伤的队友、172)、止息(突进对象、242)、清心(敌我各半、10)都是单目标：
  不带【群攻】的双模，①【基本】固定值——打出去的葵花籽伤害等量长回生命最少的队友身上(光合作用)，打队友就直接回血；② 冷却 3 秒按触发数值放大(止息、护理吃这一段)。
  导向(多目标)不在这把的路子上；屏息带着有效果的武器要瞄到 2 倍生命才开枪，固定值对她没用(+1)：fit_remove。

## 教训

- **"偏谁"要用只对一只有用的属性来调**：两把绿法器的清心 / 守林增量一开始是反的；守林的整套技能都按法强算、清心的符全是固定值，
  所以法强只影响守林——葫芦去掉法强、图腾留一点，两把的倾向就分开了。(守林的搜索对法强本身不敏感：55 → 55，但同强度看得出来。)
- **清心单目标的固定值效果太窄**：她一场只响五六次、一次一个人，给一个人加 50 最大生命几乎不动；加上【溅射】(目标身边的队友 / 敌人全额)才有 +7。
- **灭罪吃"每一下的固定伤害"，不吃易伤 / 法强**：她的插槽一秒 2 次、每次两三个敌人，【基本】12 魔法 = 一秒六七十点；萤光(受伤 +8%)和法强都几乎没动。
- **导向(法器)的基线在 64 级附近很平**(66 / 70 / 74 级 58% / 65% / 60%)，搜索的增量会被放大，看同强度。止息(步枪)也一样：搜索基线 52，64 级只有 48%。
- 屏息拿弓 / 步枪带固定值效果的武器还是不行(向日葵 +1)；放大溢出伤害的才行(箜篌敌人那边 × 160% +7)。
