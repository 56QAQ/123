口径：基础阵容 速射 / 架盾 / 耕植(各带专武) + 这只棋子 ★2；不换大类的基线 `<棋子>:2:-`，换大类的 `<棋子>:2:basic_<大类>`；`run_intensity.sh` 最高通过强度。
"同强度胜率"是固定强度、同一组配怪(公共随机数)、同一种站位打 40~80 场(`lo=hi=start=<强度> min=… max=… deploy=…`)。
明细：`out/int_gen7_base`(基线)、`out/int_gen7_r1` ~ `r6`、`r1b`(圣战 / 和星)、`r2c`(85 级对比)。

## 设计理由

先用 `intensity_bench mode=fitprobe class=dual / sword / heavy` 量了每个格子里能装的棋子"拿上这个大类以后"的触发器
(结果 `out/gen7/fit_*.txt`)，再按适配标签(敌我 / 目标数 / 频率)给每把挑一类插槽：

- **彩绸双刃(双模【基本】【群攻】)**：双匕黄 2 费的格子里只有舞星需要双模(笑给全队 0.8 次/秒、泪打敌人)，【基本】【群攻 4】的双模正好也配狂猎的"再来一次"
  (即将倒下时打身边一圈的敌人，对敌人 · 多目标 · 低频)。给队友的是叠层的攻击 + 物理吸血(和号令短剑 / 和弦音叉的攻速 buff 错开)，
  给敌人的是放大伤害：狂猎的触发数值 ≈ 730，砍出去的伤害带着吸血，正好在倒下前把血吸回来。
- **雾隐双刃(双模，冷却)**：青双匕能装的是踏影(逆光 → 自己，触发数值 = 淬血付掉的生命)、巧运(进账 → 自己)、追猎(闪避 → 攻击者)——
  一边是"打自己的低频插槽"，一边是"打敌人的低频插槽"，用不带【群攻】的双模。携带者先拿【雾隐】(pre_effects：每次发动一次，不管目标是谁)，
  所以追猎闪避一次就给自己加闪避，越闪越勤；打自己的那一边给 触发数值 × 150% 的护盾，把踏影淬血付掉的生命垫回来。
- **鎏金军刀(固定值【基本】+ 自身叠攻速)**：黄单手剑的正行 / 炽照 / 无我都是"对敌人 · 单体 · 高频"，【基本】的固定伤害 + 每扣一次给自己 1 层【锐势】。
  和蚀月(学习)、号令短剑(给目标加 buff)、回响刃(双模 + 回充能)都不撞。
- **裁誓仪剑(固定值双模【群攻 3】)**：紫单手剑能装的执剑 / 和星(对队友 · 多目标)、共歌 / 架盾(需要双模 · 多目标)、圣战(对敌人 · 多目标)都是多目标低频，
  触发数值从 25(架盾)到 490(执剑)差 20 倍，所以只给不吃数值的状态：队友减伤、敌人易伤。
- **雷鸣巨剑(放大【群攻 5】+ 眩晕)**：黄双手剑里"对敌人 · 多目标"的是锁芯和狂猎。眩晕用通用的【眩晕】状态(`status_id: stun`)，
  锁芯的深空之门按全场被眩晕的秒数触发、她的血色仪式还加长我方眩晕——武器的眩晕又攒下一扇门。
- **蚀骨巨剑(固定值【基本】叠毒)**：绿双手剑里扣得勤的单体插槽是无我和炽照，叠层的魔法持续伤害(每次刷新持续时间)，和碎岩巨剑(碎甲)不撞。

## 调数值的经过

- 彩绸双刃：首版即定稿(舞星 +11 略高，在"+4~+10 左右"的边上)。
- 雾隐双刃 6 轮：① 只有给队友的【雾隐】(闪避 20% + 攻速 20%，10 秒)：踏影 +1 / 巧运 +3 / 追猎 +0(40 级的墙)；② 雾隐加攻击 20%：+3 / +3；
  ③ 再加攻速 10%、闪避 15%、雾隐 12 秒：+3 / +1——同强度对比巧运拿不拿都一样(44 级 68% vs 66%)，踏影 72 / 74 级 53% → 66%；
  ④ 改成"自己先拿雾隐 + 队友护盾 × 100%"：踏影 +3、追猎 +7(过了 40 的墙)；⑤ 护盾 × 150%：踏影 +10(72 / 74 级 53% → 71% / 70%)。
  踏影加攻击力反而要多付淬血(淬血按攻击力算)，护盾把这一口血垫回来才是他要的。
- 鎏金军刀 2 轮：首版 25 点、锐势叠 8 层：正行 +4 / 炽照 +11 → 30 点、叠 6 层：+8 / +10。
- 裁誓仪剑：首版即定稿。架盾卡在 40 级的墙下(39 级 70% vs 70%)，圣战 +1，执剑不带武器就 ≥100 测不出来——合手定为共歌 / 和星。
- 雷鸣巨剑 5 轮：攻击 +25 / × 60% / 眩晕 0.8 秒 / 【群攻 3】：锁芯 +2、狂猎 +8；× 80% / 1 秒：+3 / +12；攻击 → 攻速 + 生命、× 60%、1.5 秒：+2 / +8
  (同强度 +22~25 个百分点，但 59~61 级那几组配怪对锁芯特别难)；眩晕 2 秒：+2 / +8；【群攻 5】：+4 / +8。
- 蚀骨巨剑：首版即定稿。无我和炽照都撞在 84 级的墙上(两边都是 83)，用同强度胜率看炽照。

## 模型

都在 `tools/weapons/gen7_models.gd`，颜色写死(不用调色板里会换色的青色系)，握法 / 尺寸照同大类现有武器。预览 `out/wpn_gen7/`
(`idle.png` 待机三视角、`close_dual.png` / `close_sword.png` / `close_heavy.png` / `close_blight.png` 特写、`attack.png` 攻击 5 帧；
预览脚本 `out/gen7/wpn_shot.gd`)。

- 彩绸双刃：柳叶形银刃、中线金色血槽(微光)，金护手两端往刃卷，暗红漆柄缠金线；柄头小环系一长一短两条绸带(金黄燕尾 + 红)，往 -Z 垂。
- 雾隐双刃：雾青色单刃(刀背直、刃口外弧、尖部斜削)，刃面一道起伏的雾纹散着发光雾点；卷云护手；深藏青柄缠青绳菱格；柄尾圆环垂一束青流苏，末端一团发光的雾。
- 鎏金军刀：微弯的淡金刀身、近白刃口、深金血槽；旭日护手(半圆金盘 + 光芒，Y-Z 平面两面都看得见)；刃口一侧的护指弓；象牙白柄缠金丝，柄头嵌橙色日珠。
- 裁誓仪剑：银白直刃，中线深紫血槽里一枚枚发光紫符文；天平剑格(银横梁、两端金链 + 金托盘、正中银座嵌紫水晶)；深紫柄缠银丝；柄头大紫水晶(发光)。
- 雷鸣巨剑：暗铁灰宽刃 + 黄铜刃口，刃心一道之字形闪电纹(亮黄芯 + 金黄光晕，贯穿两面)；黄铜剑格两端折线形雷翼；皮柄黄铜箍，黄铜配重嵌黄宝石。
- 蚀骨巨剑：骨白刃身长着苔绿斑、骨齿刃口、钩尖；裂纹网里渗着发光毒绿，刃口挂几滴毒液；肋骨状骨刺剑格；暗苔绿缠柄三道骨箍；柄尾圆骨疙瘩，眼窝透绿光。

## 教训

- 墙(40 / 50 / 84 级)下最高通过强度经常不动：同强度、同配怪、同站位打 40~80 场比胜率，几分钟就能看出差别(这一批的锁芯、炽照、踏影都靠这个判断)。
  搜索路径上某一级的配怪特别难(锁芯 61 级、踏影 72 级)时，数值稍微变一点结果就跳好几级，不要只看一次的数字。
- 打自己的低频插槽，"给自己 buff"不一定有用：巧运拿攻击 / 攻速 / 闪避同强度胜率完全不变；踏影的淬血按攻击力扣血，加攻击力反而多付血——
  看清插槽的触发数值是什么(踏影 = 付掉的生命)，按它回报(护盾)才对路。
- 双模武器想让"打敌人"那一边也给携带者加东西，用 `pre_effects`(每次发动作用于自己一次)，别用 `extra_effects`(按目标逐个、而且敌我两边都吃)。
- 狂猎吃攻击力(狼狩、再来一次都按攻击力)，锁芯的万物闭锁是固定伤害、按普攻次数算：同一把武器想两边都合手，属性要选攻速 / 生命这种两边都吃的，
  效果上多目标(【群攻 5】)只有锁芯吃得满。
