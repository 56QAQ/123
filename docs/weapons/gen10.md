## 设计理由

先量了拿上这个大类以后的触发器(`intensity_bench mode=fitprobe`；单手剑用 gen7 的 `out/gen7/fit_sword.txt`，双匕 / 法器 / 弓是 `out/gen10/fit_*.txt`)：

- **青藤剑**(绿单手剑)：能装的四只里，无我 / 炽照是"对敌人 · 单体 · 高频、触发数值小"(1.4~1.6 次/秒，56~90)，守林 / 耕植是"对自己 · 低频、触发数值大"(323~349)。
  所以做成两段双模：①【基本】固定值——每扣一次给携带者长一层本场不掉的【抽枝】(攻击 + 生命上限：绿 = 生长)，高频插槽几秒长满；
  ② 冷却 3 秒的 触发数值 × 100% 回复(敌人那边什么都不做)——给守林每次变身后补一大口。和已有的绿色近战(炽霞：放大伤害；蚀骨巨剑：叠毒)、
  鎏金军刀(短时攻速)都不撞：这把是"越打越壮"。
- **刻时剑**(蓝单手剑)：蓝色羁绊的属性是计时加速，于是做成"时钟"：每次发动先给携带者叠【超频】，"每 x 秒"的被动(和星的微笑 3 秒、圣战的猛击 5 秒、
  架盾的护盾充能)和武器冷却都走得更快；双模【群攻 3】配三只"多目标"插槽(和星 = 自己 + 护星，圣战 = 猛击打到的一片，架盾 = 自己 + 身边敌人)。
  和星的触发数值大、3 秒一次还两个目标，护盾倍率稍高他就 +18——护盾压到 × 35%，伤害放到 × 180%(只有圣战 / 架盾吃敌人那一边)。
- **血宴长剑**(红单手剑)：能装的守誓 / 狩胜 / 共歌里，前两只都是"打自己"(狩胜每次击杀、守誓觉醒时)，共歌是敌我都有的多目标——一把装不下三只，选了前两只。
  狩胜的触发数值小(36)、一场十几次，守誓的大(715 = 50% 最大生命)、一场一两次：每次给一层本场不掉的【血宴】(层数狩胜吃)，再回复 触发数值 × 300%、
  溢出的变护盾(守誓吃：觉醒以后誓血仇每一刀都扣 10% 最大生命，一大口回血 + 护盾 + 吸血正好)。
- **流水双刃**(青双匕)：三只插槽都很少响(一场一两次)。和雾隐双刃(青 3：雾隐 + 放大护盾 / 伤害)错开：固定值 + 一对正反的流速状态(队友加速、敌人减速)，
  吸血不加攻击力(踏影的淬血按攻击力扣血)。
- **蛇牙双刃**(绿双匕，只有追猎 / 巧运能装的薄格子)：两只的插槽一场一两次，所以给的东西都本场不消退(【蛇行】叠层)，属性给 4 费的量；
  敌人那边是叠层的蛇毒(打在追猎盯着的最危险的敌人身上)。巧运吃的是生命和攻击(拿暴击的猩红獠牙 +0、攻速 / 闪避的流水双刃 +1)。
- **杨柳净瓶**(绿法器，只有清心 / 守林能装)：清心的道法自然敌我各半、触发数值 10 → ①【基本】固定值的一对状态(甘露：受治疗 + 回血；枯萎：减攻 + 减受治疗)，
  正好跟着她的清心符(治疗的队友)和弱体符(物理输出最高的敌人)走；守林的原初血脉 323 → ② 放大的回复。和荆棘手弩(再生 / 荆缚)、和弦音叉、晶壁手镜都不撞。
- **夜莺长弓**(紫弓，追加)：护理和和星拿弓时触发器都是"对队友"：护理 1 个受伤的队友、0.08 次/秒；和星 自己 + 护星、0.33 次/秒、数值 291。
  任何按触发数值放大、或者冷却短的效果都会让和星吃到护理的 4~5 倍，所以两段都冷却 10 秒(两只差不多勤)、不带【群攻】(和星只给一个)，
  属性不给攻击 / 法强(会放大和星的触发数值)。和星的触发器是多目标、武器无【群攻】：按测强度 fit_add。

## 教训

- **两只触发器频率差很多、又都打队友时，放大效果一定偏向勤的那只**(和星 3 秒一次 × 2 个目标 vs 护理 13~18 秒一次)：冷却拉长到两只差不多勤、去掉【群攻】、
  属性别给会放大触发数值的(攻击 / 法强)，才能把和星从 +18 压到 +10。
- **触发器一场只响一两次的棋子，武器效果碰不到它**：护理拿弓、巧运、守誓都是这样，属性和"本场不消退"的东西才算数；护理拿弓连属性(生命 / 攻速)都改不动胜负。
- 狩胜拿血宴长剑涨的是属性(生命 / 吸血 / 攻击)不是层数：压每层数值没用，压攻击力才降下来；守誓的誓血仇按最大生命算，攻击力对他影响小——用这个差别把两只拉开。
- 墙下(40 / 50 / 62 级)看同强度胜率：架盾、圣战、守誓、追猎都是这样定下来的；踏影的搜索路径在 74、80 级都是 70% 边缘，单看最高通过强度会高估。
- 构建：机器满载时 `run_kits.sh` 的 240 秒超时不够(一次 270~340 秒)，直接 `tools/with_build_lock.sh timeout 1200 "$GODOT" --path . --script res://tools/build_kits.gd --quit-after 20`。
