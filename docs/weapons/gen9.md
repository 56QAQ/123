## 设计理由

先用 `intensity_bench mode=fitprobe class=polearm / heavy` 量了每个格子里能装的棋子"拿上这个大类以后"的触发器(结果 `out/gen9/fit_*.txt`)，
再按适配标签(敌我 / 目标数 / 频率)给每把挑一类插槽，尽量让六把各占一类、和现有的通用双手剑(碎岩 = 放大 + 碎甲、雷鸣 = 群攻眩晕、蚀骨 = 叠毒)不撞：

- **凝潮长枪(对敌人 · 多目标 · 固定值【基本】)**：青矛能装的"对敌人 · 多目标"有锁芯(深空之门 450)、星旅(真实形态 75)、圣战(神圣战争 140)、血嗜(1885)，
  数值差 25 倍，只给不吃数值的控制：通用【寒气】。3 个一叠，两下就冻住(冻结 = 眩晕：又给锁芯攒深空之门的秒数；精英 / 首领不减半，但同一个单位每次冻结减半)；
  【基本】让星旅外神之貌锁血时每 0.4 秒一下的脉冲都吃得满。和 gen5 的霜棱手弩(双模，打队友给护盾)不同：这把只打敌人、带【群攻 4】。
- **曦光长枪(对队友 · 单体)**：黄矛里"打自己"的插槽有四个(守林 变身、耕植 收获时刻、狩胜 击杀、守誓 觉醒)，给护盾 + 一段攻防 buff。
  守林每次换形态(开局也算)、狩胜每次击杀都会续上；耕植 / 守誓一场只响一次，测出来 +1，用 fit_remove 去掉。
- **星轨长枪(双模 · 多目标)**：紫矛的十只棋子里多目标插槽最多(和星给自己 + 护星、幻彩 / 圣战 / 奇兴 / 星旅打敌人、共歌敌我都有)，做成双模【群攻 4】，
  一段给状态(队友【星护】护甲魔抗 / 敌人【星蚀】降攻击——和裁誓仪剑的易伤 / 减伤错开)，一段吃触发数值(队友回血 / 敌人魔法)。
- **荆棘巨剑(对敌人 · 单体 · 高频【基本】)**：绿双手剑扣得勤的是无我、炽照。不做叠毒(蚀骨巨剑)，做"每一下普攻伤害 + 固定值"的易伤：
  `na_damage_taken_flat` 写负数 = 受到的每一下普攻多吃几点(减伤之后加)，追击 / 幻影 / 拔刀连斩这种一轮好几刀的最吃它，队友的普攻也吃。
- **凯旋巨剑(对队友 · 单体【基本】，按数值叠层)**：红双手剑"打自己"的是狩胜(击杀，38)和守誓(觉醒，715)，数值差 20 倍：
  `add_stacks_from_value` = 每 20 点一层——狩胜一次击杀 2 层、慢慢叠满，守誓一次觉醒直接叠满 + 回一大口血(他的誓血仇每刀扣自己 10% 生命)。
- **涌泉巨剑(对敌人 · 多目标，放大)**：青双手剑"对敌人 · 多目标"的是圣战、锁芯、星旅、血嗜，伤害打出去变成治疗(`heal_lowest_ally`：当前生命最少的队友)，
  法强对圣战(三个技能都 × (100 + 法强)%)、血嗜(至亲的故事)都是主属性。血嗜 ★2 不带武器就 ≥100，测不出来，合手按圣战 / 锁芯算。

## 调数值的经过

- 凝潮长枪 3 轮：首版 2 个寒气、攻速 +10%：锁芯 +4、星旅 +2；3 个寒气：一样(锁芯 64、星旅 44)；攻速 +15%：锁芯 64，加测圣战(拿基础长枪 51)→ 61。
  星旅的插槽只在她倒下前那几秒响，什么武器都不太吃(碎岩巨剑在她身上也只有 +3)，留作"适配但不合手"。
- 曦光长枪 4 轮：首版 护盾 × 150%、生命 200、曦光 12 秒(15% / 20%)：守林 +10、耕植 +1、狩胜 74；曦光 8 秒(12% / 10%)：狩胜 62(+1)、守林 +10；
  10 秒(15% / 15%)、护盾 × 100%、生命 150：狩胜 +1、守林 +10、耕植 +1；回到 12 秒(15% / 20%)、护盾 × 80%：狩胜 74、守林 +10、耕植 / 守誓 +1。
  守林吃的是生命 / 护甲 / 换形态时的护盾(每一版都是 61)，狩胜吃的是曦光本身——击杀一个接一个，12 秒的曦光能一直续着，8~10 秒就断。
  狩胜的 74 两次都是搜索从 42 级直接跳到 74 级、那一级 7 场全赢，所以又测了同强度胜率(每一级 +5~+12 个百分点)。
- 星轨长枪 5 轮：首版 法强 +30、生命 200、星护 20、回复 60% / 魔法 80%、星蚀 15%：和星 67(+18)、幻彩 75(+26)；
  去掉法强、生命 250、回复 50% / 魔法 60%、星蚀 12%：61 / 70；生命 150、星护 12、回复 35% / 魔法 25%：60 / 63；魔法 15%、星蚀 10%：幻彩 63；魔法 10%、星蚀 8%：幻彩 62。
  幻彩的颜料会把武器打出去的伤害放大两倍多、法强又是她所有技能的系数，所以敌人那一边一路往下砍；两只都卡在 50 级的墙下(基线 50 级 67~69%)，
  后几版的武器效果已经很小了，最高通过强度还是一过墙就落在 60~63——按同强度胜率看是 +13~+23 个百分点(≈ +6~+8 级)。
- 荆棘巨剑：首版即定稿。无我 +8；炽照卡在 84 级的墙上，用同强度胜率看(+15 个百分点)。
- 凯旋巨剑 3 轮：首版 攻击 +25、生命 +150、回复 × 100%：狩胜 +6、守誓 +3(49 级 68% 差一点)；攻击 +35、生命 +200：+8 / +3；回复 × 150%：守誓 50(+5)、狩胜 70(+9)。
- 涌泉巨剑 2 轮：首版 × 30%、法强 +40：圣战 +2、锁芯 +3(对基础双手剑)、血嗜 ≥100；× 70%、法强 +50：圣战 +6、锁芯 +4、星旅 +1(fit_remove)。

## 适配修正(fit_add / fit_remove)

- 曦光长枪 `fit_remove=["node_peasant", "node_darkknight"]`：耕植(收获时刻)、守誓(起誓之时)每场只响一次，测出来都是 +1(耕植 44 → 45；守誓 拿基础长枪 44 → 45)。
- 涌泉巨剑 `fit_remove=["node_astronaut"]`：星旅(真实形态)拿基础双手剑 44 → 45，+1。
- 没有 fit_add。凝潮长枪的星旅 +2 留着(不是 +0)；血嗜两把都适配但 ★2 测不出来，也留着。

## 教训

- **搜索路径会骗人**：狩胜拿曦光长枪第一次测出 74(+13)，其实是 42 级直接跳到 74 级、那一级的 7 场配怪恰好都赢了，58~73 根本没测；
  同一把武器削一点再测就掉回 62。数字跳得离谱时先看明细里测了哪几级，再用同强度胜率确认。
- **50 级的墙**：和星(49)、幻彩拿基础长枪(49)都卡在 50 级下面(50 级 67~69%，差一两场)，随便什么有用的武器都能把它们推过墙，一过墙就落在 58~63——
  按最高通过强度看增量会偏大，要看墙前后的同强度胜率。
- 不同插槽的触发数值差几十倍(凝潮 75~1885、凯旋 38~715)时：控制 / 固定值不吃数值；或者用 `add_stacks_from_value` 把数值换成层数、再用层数上限封顶。
- 只在倒下前那几秒响的插槽(星旅 真实形态)、一场只响一次的插槽(耕植 收获时刻、守誓 起誓之时)，武器效果几乎测不出来，属性才是主要的。
