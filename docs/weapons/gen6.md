## 设计

先用 `intensity_bench mode=fitprobe class=rifle / bow` 量了拿上这个大类以后的触发器(数据写在 `gen6_data.py` 文件头)：
步枪 速射 0.49 次/秒、数值 10；护理 0.17、172、95% 是受伤的队友；止息 0.32、242；屏息 0.16、1084(击杀溢出)；清心 0.14、10、敌我各半；
真望 只在自己阵亡时；改修 0.01、自己。弓 追猎 0.14、150；心音 0.22、90、敌 63% / 友 37%；屏息 0.11、1083。

- **双模 + 固定值**：效果配置写 `ally_effect / enemy_effect` 时按目标阵营换效果，这和结算规则无关——结算规则写 bullet(固定值)，两个分支都用 `fixed_value`，
  数值只有 10 的速射 / 清心也吃得满；FitTags 只要能力里有分支就算"提供双模"。红 / 紫两把步枪要同时配速射(对敌、高频)和护理 / 改修(对友)，只能这么写。
- **输血步枪**：护理拿它奶人时，被奶的那个队友带着【输血】，之后她的每一针治疗都 +40%(和她"一直盯着血最少的那个人"的习惯配合)；速射每 3 发给敌人挂一道独立的物理持续伤害。
  (gen5 的救难信号弩是红色"燃烧 / 回血 + 放大回血"的组合，这把刻意换成了增益 / 放血，避开撞概念。)
- **乘势连发枪**：黄色的"金锐"——越打越顺手的自增益(乘势) + 一段吃触发数值的放大伤害，第二段给屏息的"一石二鸟"用。
- **回潮步枪**：真望的武器触发器只在她自己阵亡时响，目标是阵亡的自己——一般的效果都落空。第二段用现成的【限制】关键词(`limited_timings: OnUnitDied`)
  + `once_per_battle` + `revive_dead`：只有"有人阵亡"时机的触发器才发动，每场限一次，让她原地复活；清心的触发器(被动技能的目标)只吃第一段的治疗 / 伤害。
- **咒纹步枪**：紫色的"紫电"——给队友的普攻附带魔法伤害；改修只有生命 < 50% 时才触发(而且会扣一层适应改造)，所以第二段给护盾，再加法强(适应改造的暴击率 ×(100 + 法强)%)。
- **逐风短弓**：顺风 / 逆风的速度增减益 + 放大的一刀；追猎闪开的多半是她盯上的首领 / 精英，逆风减的是那只的攻速。真望同样只靠属性。
- **金乌长弓**：双模 +【学习】：心音的演奏对象敌我都有，奶队友、打敌人，越打越强；追猎、屏息拿到放大的伤害。

外观：都是专属模型，写死颜色(不用会被换色的调色板青色)。输血步枪 = 白漆红条 + 枪托两侧的血袋和软管 + 枪管下的血清药管；乘势连发枪 = 金色机匣的杠杆连发枪(大杠杆环、管状弹仓、
胡桃木、旭日纹)；回潮步枪 = 珍珠白 + 青色鳞纹护木 + 枪管上的海水玻璃管 + 海螺枪口 + 托底卷着一道浪；咒纹步枪 = 乌木 + 银 + 发光的紫色咒文 + 紫晶；
逐风短弓 = 浅桦木反曲短弓 + 青色握把 + 两束白羽青梢 + 飘带；金乌长弓 = 金色长弓 + 握把上方的日轮 + 弓梢的乌鸦黑羽 + 金白的弦。
投射物：回潮步枪射水弹(`g6_tide_drop`：半透明水珠 + 水痕 + 甩出的水滴，命中溅开)，金乌长弓射带日光的金箭(`g6_sun_arrow`：发光的箭 + 箭头的小太阳 + 金色光带 / 火星，命中一轮小日冕)；
另外四把射这个大类默认的子弹 / 箭。步枪的出手特效从扳机手往前挪到枪口(0.45 米)。

## 调数值的经过(5 轮)

1. 首版：输血(攻击 +20、受治疗 +30%、放血 20)速射 51 / 护理 51；乘势(r 0.4、冷却 2.5 秒)速射 49 / 止息 61 / **屏息 64(-7)**；回潮 清心 44 / 真望 60；
   咒纹(只有第一段)速射 49 / 护理 53 / 改修 61；逐风(攻速 15%、× 80%)追猎 39 / 真望 48；金乌(× 50%)心音 49 / 追猎 42 / 屏息(弓)63。
2. 屏息为什么带上武器反而变弱：`battle_ai._aim_done`——**屏息拿着有效果的武器时会瞄到能打出目标生命 2 倍的伤害才开枪**(溢出的伤害交给一石二鸟)，
   开枪变慢；武器带过去的溢出伤害不够多就亏。乘势第二段 r 0.4 → 1.0：-1；加【暴击】：+1；去掉冷却(【基本】，能连杀；当时还带着生命 +100)：+3；生命换成暴击伤害 +30%：+6。
   金乌同理：× 0.5 → 0.8 + 暴击：+0；× 1.2：-2(噪声)；再加暴击伤害 +30%：+8。
3. 速射 / 真望卡在 50 级的墙下：速射带输血(生命 +150)、咒纹(加了生命 +120 以后)能过 50，带乘势(没有生命)过不去——这只 1 费射手主要缺的是活下来；
   真望 50 级那几场的胜负和不带武器一模一样(墙是整队的)，逐风加攻击、生命以后 49。
4. 太强的往回收：咒纹加 120 护盾时护理 60(+11)，降到 70 + 生命 120 → 53；乘势加生命 +100 时止息 65(+13)，换成暴击伤害 → 61。
   改修一直在 +10(法强 30 → 20 也没变)，留在上限。

## 教训

- **屏息 + 有效果的武器 = 瞄得更久**：给她的武器必须把溢出伤害放大带走(放大 ≥ 1、能暴击、不吃冷却)，否则比基础武器还弱。
- 速射 / 真望 / 心音这几只基础阵容附近的棋子都卡在 40 / 50 的墙下，最高通过强度对武器不敏感：比同一强度(墙上那一级)的胜率。
- 心音在 42 ~ 49 级的胜率曲线几乎是平的(都在 70% 附近)，最高通过强度噪声 ±4：看 46 级的胜率(69% → 92%)更可靠。
- 双模的分支和结算规则是独立的：bullet + 分支 = "固定值双模"。【限制】(`limited_timings`)可以把一段效果限定在某种时机的触发器上(这里是"有人阵亡")。
- 生命对几只脆皮(速射、真望)比伤害更值钱；对近身的止息也很值钱(加生命 +100 就从 +9 变成 +13)。
