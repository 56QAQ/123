口径：基础阵容 速射 / 架盾 / 耕植(各带专武)+ 这只棋子 ★2；除了白羽(`node_angel:2:-`)都换了大类，基线是 `<棋子>:2:basic_pistols`。
"40 / 42 级 x% → y%" = 同一强度、同一组配怪(公共随机数)打 60~100 场的胜率(墙下面的棋子：速射 / 架盾 / 浪游 / 巧运 / 清心拿手枪都是 38~39)；
其余是 `run_intensity.sh` 的最高通过强度。

基线(★2，拿基础手枪)：速射 38、架盾 38、浪游 38、巧运 39、清心 39、止息 48、护理 49、白羽 52(基础大类就是手枪)、导向 52。
同强度胜率的基线：速射(前压)40 / 42 / 44 级 70% / 58% / 55%；清心(前压)40 / 42 级 57% / 52%；浪游(抱团)65% / 59%；巧运(抱团)71% / 65%。

## 设计理由

- **豌豆荚双枪(绿 2)**：三只能装的棋子都是"打自己 / 打一个人"的低频插槽(浪游 / 巧运 = 自己，清心 = 她的符的目标，敌我各半)，所以是不带【群攻】的固定值双模。
  关键是**溅射**：护盾 / 荚衣不只给触发目标，还给它身边 2.4 米内的队友(`splash_filter: target_allies`，敌人那一侧溅的是伤害)。
  浪游总贴着敌人打，身边多半是在和同一群敌人缠斗的前排；清心的清心符给的是伤得最重的队友(前排)——荚衣一溅就是整个前排。
  眩晕单独一段、不溅(否则清心一张弱体符就晕一片)。
- **铆钉双枪(蓝 2)**：维护部的铆钉枪给队友的护甲打补丁。架盾的"盾，我的盾！"在护盾碎掉时触发，目标是自己(不带【群攻】时只有她自己)——
  每碎一次就给自己和身边的队友补一层护盾、叠一层铆甲，护盾又碎了又再补。架盾的插槽标签是"需要双模 · 多目标"(拿【群攻】的武器时会打到身边的敌人)，
  这把没有【群攻】、只会打到她自己，标签对不上，所以 `fit_add`。
- **调剂镖枪(紫 3)**：护理拿手枪药水填充 0.6 次/秒、全打在受伤的队友身上——强心剂 + 第三段的治疗；速射每 3 发给目标一针：神经毒叠满(攻速 -30%、受伤 +18%)
  + 0.5 秒麻醉(通用【眩晕】，同一个目标反复扎就一直在晕和醒之间)。
- **千纸鹤双枪(青 3)**：白羽要的是活下来(gen5 青岚的教训)，`pre_effects` 每次发动给携带者一层护盾(不管打谁，一次发动一次)，再给 3 个敌人一点伤害 + 纸割；
  架盾的触发目标是自己 + 身边的敌人：自己拿两层护盾(pre_effects + 队友分支)，身边的敌人挨纸割。
- **庆典烟花筒(红 4)**：一发烟花在目标身边炸开(【溅射】)：打在敌人头上是伤害 + 耳鸣，**炸出来的伤害化作治疗落到血最少的队友身上**(`heal_lowest_ally`)；
  打在队友身边是回血 + 庆典(攻击 / 攻速)。速射每 3 发炸一次，护理每 3 针炸一次。
- **金阳射线枪(黄 4)**：导向的电闪(一串敌人，138)和止息的突击(突进对象，242)都是"数值大、几秒一次"的插槽：放大 ×120%【群攻 3】+ 炫目。
  止息的插槽是单体，【群攻】对她不影响(只有一个目标)，标签对不上，所以 `fit_add`。

## 调数值的经过

明细：`out/int_gen8_r1` ~ `r7`(最高通过强度)、`out/int_gen8_c2` ~ `c5`(同强度胜率曲线，`out/gen8/curve.sh`)、`out/gen8/probe/`(n = 100 的同强度胜率 +
第 4 只棋子的阵亡时刻 / 伤害 / 承伤 / 护盾 / 触发次数，`out/gen8/unit_probe.gd mode=unitprobe`：intensity_bench 的拷贝，多一个模式，还能在内存里改武器数值做试验，不动数据文件)。

- **豌豆荚**(4 版)：① 只给触发目标(护盾 45、荚衣 20% 6 秒、眩晕 1 秒、生命 150)：清心 40 / 42 / 44 级 62% / 53% / 57% → 72% / 58% / 55%(+4)，浪游 -7 个点；
  ② 数值全加(生命 180、装填 -20%、护盾 55、荚衣 25% 8 秒、眩晕 1.5 秒)：清心 57% / 52% → 71% / 67%(n = 100)，**浪游 65% / 59% → 64% / 58%(+0)**。
  用 unit_probe 查浪游：**他平均开战 9.4 秒就倒下**(一场 37 秒)，带上武器多活 2.4 秒、伤害 +46%，再加 30% 闪避 / 25% 吸血也只活到 14 秒、伤害 +77%——胜率一点不变。
  第 4 只棋子自己的输出 / 存活决定不了 40 级那几场的胜负，能改变胜负的是"保护前排"(清心 +14 个点靠的就是给伤得最重的队友荚衣 + 砸晕最大的物理输出)。
  ③ 护盾 / 荚衣改成溅给触发目标身边的队友(浪游贴着敌人打，身边多半是缠斗中的前排)：浪游 78% / 77%(+13 / +18)，清心 82% / 79%(眩晕也溅了：一张弱体符晕一片)；
  ④ 眩晕拆成单独一段、不溅，1.5 → 1 秒：清心 80% / 76%(+23 / +24)，浪游不变。
- **铆钉**：① 【基本】护盾 40 + 溅射：架盾 38 → 49；② 护盾 35：49；③ 改成冷却 5 秒、护盾 90(想让很少触发的巧运一次拿得多一点)：架盾 42、巧运还是 +0 → 回到 ②。
  巧运：40 / 42 / 44 级(抱团)46 / 37 / 40 → 42 / 39 / 38(60 场)、40 / 42 级 71% / 65% → 70% / 62%(100 场，冷却版)。
- **调剂镖枪**：① 神经毒(攻速 -8%、受伤 +5%)+ 强心剂 + 冷却治疗：护理 49 → 58(+9)，速射 38 → 39；② 神经毒加到 -10% / +6%：速射同强度 +1 个点(42 / 35 / 33 → 43 / 36 / 34)——
  **光加减益没用**(gen5 的教训：控制比伤害值钱)；③ 加一段 0.5 秒麻醉(通用眩晕)：45 / 42 / 38(+3 / +7 / +5 场 = +5 ~ +12 个点)。护理只吃队友那边，不受影响。
- **千纸鹤**：① 自身护盾 25、伤害 / 队友护盾 30、纸割 3%：白羽 52 → 55、架盾 38 → 48；② 自身 30、纸割 4%：55；③ 自身 35、伤害 36：白羽 56(+4)、架盾 48(+10，卡 50 级的墙)。
- **烟花筒**：① 攻击 +30、①段回复 / 伤害共用 40、庆典 12%、放大 80%：护理 49 → 61(+12)，速射 38 → 40(同强度 +1 ~ +2 个点)；
  ② 放大 50%：护理还是 61；③ 回复拆成单独的 30、庆典 8%、伤害段加 heal_lowest_ally：护理 61(没变)，速射 45 / 40 / 40(+3 / +5 / +7 场)；
  ④ **护理吃的是攻击力**(她的普攻 = 治疗)：攻击 30 → 15、伤害 50：护理 53(+4，54 / 58 级抱团 60% / 61%)，速射 46 / 40 / 37；
  ⑤ 攻击 20(定稿)：护理又是 61。同强度看：56 级 基础手枪 44% / 攻击 15 75% / 攻击 20 72% / 调剂镖枪 75%——两种攻击力一样强，

  54 级同强度(前压，100 场)：基础手枪 41%、×120% 53%、×160% 55%——倍率对她也不敏感，定稿 ×120%(攻击 +20)。

## 教训

- **第 4 只棋子的输出 / 存活往往决定不了墙上那几场**：浪游 / 巧运开战 9 秒左右就倒下，给他们再多的生命、减伤、吸血，伤害 +77% 胜率也一点不动。
  能改变胜负的是**保护前排**(给伤得最重的队友减伤、把护盾溅给身边缠斗的前排)和**控制**(眩晕 / 麻醉最大的威胁)。
  打自己的低频插槽，效果做成"溅给身边的队友"(`【溅射】+ splash_filter: target_allies`)比"给自己"有用得多。
- **护理拿手枪吃攻击力**：她的普攻是治疗，武器上的攻击力 +30 比任何效果都值钱(烟花筒改了三版效果护理都是 61，攻击力降到 15 立刻 53)。
- 墙下面比同强度胜率要 100 场才看得清：60 场的曲线 ±6 个点，同一套阵容换个武器能差 ±4 场(浪游第一次的 -7 个点就是噪声 + 真的没用)。
- 最高通过强度在 52 ~ 58 这一段很跳(止息 51 / 60 / 51 / 60)：前 7 场全胜直接判通过、往上跳，一组难配怪就判不通过。看 54 级前后的同强度胜率更稳。
- 清扫拿手枪不近战，女仆护身术一次都不响(fitprobe 0 次)；巧运的进账一场 1 ~ 2 次。这两只在手枪格子里基本只能吃属性。
