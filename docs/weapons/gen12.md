## 设计理由

先用 `intensity_bench mode=fitprobe class=polearm / sword / heavy` 量了每个格子里能装的棋子"拿上这个大类以后"的触发器(`out/gen12/fit_*.txt`；
和 gen7 / gen9 量的完全一样)，再按适配标签给每把挑一类插槽，六把的合手棋子尽量不重样，概念避开已有的同大类通用武器：

- **鲸歌长枪(蓝矛 · 双模【群攻】)**：蓝矛能装的五只里，灾星不能装【双模】、巫术是单体高频，剩下和星(对队友 · 多目标)、圣战 / 星旅(对敌人 · 多目标)——只有双模【群攻】能同时配上。
  蓝色羁绊是"法强 + 计时加速"，所以给队友的是【鲸歌】(法强 + 计时加速：和星的微笑 / 光箭都 × (100 + 法强)%，计时加速让每 3 秒的微笑和武器冷却都更快)，
  给敌人的是【深压】(降魔抗、减速：圣战的裂地猛击是魔法伤害，下一锤更痛)，第二段再打 触发数值 × 100% 的魔法伤害(先压再打)。
  和刻时剑(给自己超频 + 护盾 / 魔法)、星轨长枪(护甲魔抗 / 降攻 + 回复 / 魔法)、裁誓仪剑(减伤 / 易伤)错开。
- **翠竹长枪(青矛 · 对队友 · 单体【基本】)**：青矛"打自己"的插槽是守林(开局 + 每次换形态，323)和耕植(生命首次低于 50%，一场一次，349)，
  两只都是前排、数值差不多。给的是"折了还会再长"：一大口回复 + 本场不消退的【竹韧】回血(按这一次的触发数值重算，不累加——守林一场扣 4 次也不会滚雪球)。
  和曦光长枪(护盾 + 短时攻防)、凯旋巨剑 / 血宴长剑(按数值叠攻击 / 吸血)不撞：这把只管"活下去"。
- **金雀细剑(黄单手剑 · 对敌人 · 单体【基本】)**：黄单手剑扣得勤的是正行(0.65 次/秒)、炽照(1.36)、无我(1.58)，都是近战单体输出。
  鎏金军刀(固定伤害 + 自身叠攻速)已经占了"叠攻速"，这把叠的是暴击率 + 暴击伤害(【雀跃】)，打出去的固定伤害本身也带【暴击】。
  无我的追击和幻影一刀刀都吃暴击，所以她涨得最多(过了 84 级的墙)。
- **紫藤长剑(紫单手剑 · 双模【群攻 4】)**：紫单手剑能装的九只里，多目标插槽最多(执剑 / 和星 对队友，共歌 / 架盾 敌我都有，圣战 对敌人)。
  共歌的善良地每 5 秒对所有醉了的人触发、数值 = 30 × 目标的沉醉层数——醉得越深的队友回得越多、醉得越深的敌人挨得越痛；
  第二段是不吃数值的一对状态(队友全能吸血 / 敌人减速 + 减疗)。和裁誓仪剑(减伤 / 易伤)、刻时剑(护盾 / 魔法)、双生烛台(回复 / 魔法)比，这把多了吸血和减疗。
- **梦魇巨剑(紫双手剑 · 对敌人 · 多目标)**：紫双手剑里"对敌人 · 多目标"的是幻彩、狂猎、圣战、星旅。给的是不吃数值的削弱(攻击力 / 攻速一起降)，
  再加一点魔法伤害——幻彩的颜料会把武器打出去的伤害放大两倍多(星轨长枪的教训)，所以伤害倍率压得低，主要靠【梦魇】：
  她吟唱少女幻终时嘲讽着一圈敌人、自己 80% 减伤，身边的敌人都在做噩梦。狂猎的再来一次在倒下前把身边一圈的敌人削弱 + 打一下。
  和雷鸣巨剑(眩晕)、碎岩巨剑(碎甲)、涌泉巨剑(伤害转治疗)、星轨长枪的星蚀(只降 8% 攻击)都不一样。
- **金钟巨剑(黄双手剑 · 双模【群攻 4】)**：黄双手剑里，狂猎 / 锁芯 是"对敌人 · 多目标"(雷鸣巨剑也是给这两只的)，共歌是"敌我都有"——
  做成双模，队友那边是金钟罩(触发数值 × 60% 的护盾)，敌人那边是钟声(物理伤害 + 震退 1.2 米)。
  狂猎在倒下前把身边一圈的敌人震开，共歌醉了的队友罩上金钟、醉了的敌人被震开。

## 调数值的经过(明细 `out/int_gen12_r1` ~ `r7`)

- 鲸歌长枪 5 轮：首版第二段只打敌人：圣战 +9、和星 49 → 51(+2，刚过 50 级的墙)；第二段加队友回复 × 40% / × 70%：和星都是 53(54 级前压 62% / 69%)；
  回复换成护盾 × 50%：和星 60(+11)；× 30%：53；× 40%：56(+7，定稿)。和星吃的是护盾(gen10 刻时剑也是这样)，回复几乎不动。圣战只吃敌人那一边，不受影响。
- 翠竹长枪：首版即定稿(守林 +10、耕植 +4)。
- 金雀细剑：首版即定稿(正行 +4、炽照 +7、无我 +10；止息 +1 → fit_remove)。
- 紫藤长剑 3 轮：首版 回复 × 60%、护盾上限 20%、魔法 × 80%、吸血 12%：共歌 38(+11)、和星 63(+12)；回复 × 45%、上限 15%、吸血 10%：38 / 63；
  回复 × 30%、上限 10%、魔法 × 60%、吸血 8%：37(+10)/ 61(+10)。共歌的搜索路径很平(34 级、38 级都在 70% 上下)，基线 34 级只有 60%，同强度看是 +10~15 个百分点。
- 梦魇巨剑 3 轮：首版 × 60%、梦魇 4 秒：幻彩 72(+11)、狂猎 60(+8)、圣战 61；× 40%：幻彩 70、狂猎 56——狂猎吃的是伤害，幻彩的 70 / 72 级都在 70% 的边上；
  回到 × 60%、梦魇 3 秒：72 / 60。定稿最后一版(幻彩 +11 在"+10 左右"的边上)。
- 金钟巨剑 2 轮：首版 攻击 +25：狂猎 +8、锁芯 58 → 60(+2)、共歌 31 → 37(+6)；锁芯的万物闭锁按普攻次数算，攻击换成 攻击 +15 + 攻速 +12%：+8 / +3 / +6。
  锁芯涨得少：钟声把眩晕着的敌人震散了，下一个万物闭锁的圆圈罩不住那么多人——留作"适配但不合手"(+3，不是 +0)。

## 教训

- **和星吃护盾不吃回复**：鲸歌长枪第二段给队友回复 × 40% 和 × 70% 结果一样(+4)，换成护盾 × 50% 一下 +11，× 40% +7——他的微笑插槽目标(自己 + 护星)
  大多是满血的，回复几乎都溢出了。gen10 的刻时剑也是被护盾放大。
- **墙后面的搜索路径很平**：紫藤长剑削了两轮，和星 63 → 63 → 61、共歌 38 → 38 → 37——这一段每一级都在 70% 上下，削一点只是把 62 级的 83% 压到 74%。
  这种时候看墙前后同强度胜率比看最高通过强度准。
- **同一把武器，不同棋子吃的部分不一样**：梦魇巨剑的伤害倍率 × 60% → × 40%，幻彩 72 → 70(都在边上，差不多)，狂猎 60 → 56——狂猎的再来一次一场只响一两次，
  吃的是那一下的伤害；幻彩的颜料一直在响，吃的是削弱。想压幻彩、保狂猎，别动伤害。
- 震退这种位移效果会和"把敌人聚在一起打"的棋子打架：锁芯拿金钟巨剑只 +3(雷鸣巨剑的眩晕给她 +4)，钟声把眩晕着的敌人震散了。
- 高频插槽 + 暴击叠层对"一轮打好几下"的棋子特别强：无我(追击 + 幻影)拿金雀细剑一下过了 84 级的墙(荆棘 / 蚀骨巨剑都卡在 83)。
