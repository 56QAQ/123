## 设计理由

- **琥珀双刃(黄 4)**：七只能装的棋子里，基础大类就是双匕的止息 / 清扫和追猎都是"打一个敌人、几秒一次、触发数值大"(150~379)，所以是不带【群攻】的双模：
  放大的物理伤害 + 一下【眩晕】(封进琥珀)——止息每次突进以后那个敌人被迫打她、清扫是被近身的那一刻，封住它正好；
  打敌人那一边也要给携带者东西，用 `pre_effects` 的【琥珀甲】(减伤)，两只都是冲在前面挨打的。打自己的狩胜 / 巧运走护盾那一边。
  舞星(要【基本】)、狂猎(要【群攻】)不在这把的路子上(彩绸双刃已经是她们俩的)。
- **螳螂双镰(绿 2，只有追猎 / 巧运能装的薄格子)**：两个插槽一场只响一两次，给的东西都是本场不消退的(拟态叠层、螳斧叠层)，再给 2 费的属性(攻击 / 生命 / 闪避)；
  追猎闪开威胁目标的普攻 → 钳住它的手(攻击力本场一直低)、自己越闪越快；巧运的回复按 gen8 的教训溅给身边的队友(`splash_filter: target_allies`)。
  和蛇牙(叠毒)、流水(短时加减速)、雾隐(雾隐 + 放大护盾)都不撞。
- **催眠双枪(紫 2)**：能装的速射 / 护理 / 巧运 / 架盾 / 清扫里，速射(敌人 · 高频 · 触发数值 10)和护理(受伤的队友 · 0.6 次/秒 · 172)是这一格的主力，
  都是单体：不带【群攻】的双模，①【基本】固定值(速射吃满)，② 冷却 4 秒的一对状态——敌人【误导】(控制比伤害值钱：gen5 / gen8 的教训)，
  队友【暗示】(减伤，打在护理最想救的那个人身上)。和调剂镖枪(紫 3：神经毒 + 麻醉 + 冷却治疗)、烟花筒(红 4)都不撞：这把是"让敌人打自己人"。
  【误导】用的是幻形节点的现成效果 `mislead`(状态 `misled`，画面上有现成的表现)。
- **摇篮月长弓(蓝 2，和星的单人格)**：和星的微笑每 3 秒、两个目标、触发数值 291——gen10 夜莺长弓的教训是按触发数值放大的效果会被他吃得很大，
  所以这把全是固定值：【群攻 2】正好裹住他和护星，减伤 + 每秒回复；属性给蓝色的计时加速(微笑 / 光箭更勤一点)，不给攻击 / 法强。
- **青龙长弓(青 4)**：基础大类是弓的追猎 / 真望 + 和星。追猎拿弓时灵敏身法比拿双匕勤三倍(0.14 次/秒)、打的是威胁最高的那个敌人——
  他的意外渔获本来就让全队改打它，所以给放大伤害 + 【龙威】易伤(全队打它都更痛)；和星那一边是护盾(× 25%：他的触发数值大)。
  真望的勇气在她阵亡时才响(一场 0~1 次)，只吃属性。和星是多目标触发器、武器不带【群攻】：标签对不上，按测强度 `fit_add`。
- **玫瑰花束(红 3)**：能装的是舞星(要双模：笑给队友、泪打敌人)和基础大类是法器的护理(单体)；灾星(流星，敌我都砸)标签上也适配。
  ①【基本】【群攻 2】的固定值双模给舞星的笑(每次普攻都给两个队友献花：【芬芳】= 减伤 + 每秒回复——同强度试出来她吃的是续航)，
  ② 冷却 3 秒的放大回复给护理的药水填充；属性给攻速(护理的药水按普攻次数填充，同强度试出来她吃的是攻速)。护理是单体触发器、武器有【群攻】：按测强度 fit_add。

## 教训

- **最高通过强度在墙下会严重失真，大增量要用同强度复核**：舞星拿基础法器 53，可 64 级同强度已经 70%(她卡在 54 级那几组配怪上)；
  玫瑰花束首版搜到 68(+15)，64 级同强度其实只是 70% → 71%。止息(49，58 级已经 60%)、和星(62，66 级已经 73%)也是这样。
  同强度试几个变体(`out/gen13/ibench.gd`：intensity_bench 的拷贝，多了 drop / patch / stat / pct / mult / fixed / kw，在内存里改武器，不动数据文件)
  比反复跑完整的搜索快得多，也看得出"到底是哪一段在起作用"。
- 舞星拿法器吃的是**续航**(笑的每一下给队友回复 / 护盾 / 减伤都是 +10 ~ +16 个百分点)，攻击 / 攻速的增益几乎不动；护理拿法器吃的是**攻击速度**
  (药水填充按普攻次数算)，攻击力、治疗量、生命都只有一点点。
- 一场只响一两次的插槽(追猎拿双匕、巧运)：给的东西做成本场不消退，再加属性；回复溅给身边的队友。
- 清扫拿手枪、巧运拿手枪都和前几批一样：基本只能吃属性，标签算上了也要 fit_remove。
