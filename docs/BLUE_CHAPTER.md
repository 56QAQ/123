# 蓝之章：怪物与事件设计稿(2026-10-15)

用户："设计蓝之章怪物和事件。"在已有的 4 只普通怪物(SG-07 哨戒炮台 / RX-03 增幅中继 / HV-12 场域载具 / AX-01 突击仿生人)之上，
补齐蓝之章自己的 **2 只普通怪物、3 只精英、1 个首领**(替换掉红之章的占位)和 **3 个事件**(2 个限定 + 1 个蓝色事件，其中一个带专属战场)。
数值是初稿，标定 / 跑分之后的结果见文末「6. 实现后的结果」。

## 0. 统一的设计语言

- 世界观：蓝色穹顶下的"箱庭"——一座早就没有市民、却还在照常运转的未来都市。怪物是城市管理系统的产品(命名 = **产品编号 + 功能**)，
  它们还在执行各自的协议：安保、维修、清扫、宵禁。首领是城北信标里的**管理者**。
- 战斗原语 **【增幅】**(第一版定下的)：每只机器的被动都带【增幅 N】、效果随增幅缩放；增幅来源 = 增幅链路(状态)/ 增幅力场(地形，不分敌我)。
  这一批把"增幅"往四个新方向用：**死亡时**(殉爆)、**治疗**(维修)、**节奏**(过载 / 过热)、**全队与复活**(中枢)、**蓄力狙击**(轨道炮)、**随时间成长**(首领)。
- 蓝色的颜色原语是"每 x 秒的计时器"：精英和首领的机制都做成**看得见的倒计时 / 节奏**——玩家打的是时机。
- 每只精英一个明确的解法：步行机 = 等它过热再集火；中枢 = 先打中枢(不然打倒的机器会被重新组装)；轨道炮 = 散开站位、切掉它。

| 怪物 | 类型 / 武器 | 数值(1 星) | 被动 | 身份色 |
|---|---|---|---|---|
| **BX-09 殉爆蛛机** `mob_bx_spider` | 四足蛛形机(战士，快) / 双刃(前肢) | 攻 46 / 防 14 / 魔抗 14 / 生命 560 / 移速 3.2 | **殉爆协议【增幅 2/2/3】**：被摧毁时引爆——对 2.2 米内**所有单位(不分敌我)**造成 攻击力 × 120% × 增幅 的法术伤害 | 警示黄 + 黑斜纹 |
| **MR-05 维修无人机** `mob_mr_drone` | 四旋翼无人机(施法者，悬浮) / 法器(焊接光束) | 攻 40 / 防 10 / 魔抗 28 / 生命 640 / 移速 1.6 | **维修协议【增幅 2/2/3】**：每 2 秒，修复生命比例最低的一台友方机器(含自己)：回复 攻击力 × 75% × 增幅 的生命 | 洋红 |

- 殉爆：增幅按**死的那一刻**算——它死在中继旁边 / 力场里会炸得更狠；殉爆会把旁边另一只蛛机炸死 → 连锁殉爆；也会炸到自己人。
  解法：在它冲进人堆之前用远程点掉，或者让它死在它自己的队伍里。
- 维修：每 2 秒 60 点(增幅 2)，挂着链路翻倍——它让"火力不够的队伍"打不动；它很脆、站在后面。

阵型(新增)：蛛机 = 冲锋的终端(和突击仿生人一起压上来)，无人机 = 后排的终端(配坦克 / 炮台)。

## 2. 精英(3 只，替换红之章的占位)

### GW-20 重装步行机 `elite_gw_walker`(大型，战士 / 重武器)
两条粗腿的重装步行机甲(体型 ×2，和虚荣的余烬一样大)，左臂一柄液压锤、背上两排散热鳍。

- **震荡锤【增幅 2/3】**：普攻命中时，目标周围 2.4 米内的敌人受到 攻击力 × 30% × 增幅 的物理伤害(震荡波)。
- **过载循环**：开战 6 秒后进入【过载】5 秒(被动增幅 +3、攻速 +60%：散热鳍烧红)；过载结束立刻【过热】3 秒(**无法行动、受到的伤害 +50%**：
  跪下喷蒸汽)；过热结束后 6 秒再次过载……(一轮 14 秒)。
- 数值：攻 70 / 防 45 / 魔抗 30 / 生命 3600 / 移速 1.2 / 攻速 ×0.75。
- 解法：过载时它一锤一圈震荡波；过热的 3 秒是集火的窗口。

### CN-00 中枢主机 `elite_cn_hub`(支援，不会攻击、不会移动)
一颗悬浮的白色球形主机，三道转动的数据环，底下一座深色的基座。站在敌方阵型的最后面。

- **全频广播【增幅 2/3】**：每 4 秒，**全场所有友方**获得【增幅链路】5 秒(被动增幅 +增幅基础值；和中继的链路是同一个状态)。
- **重构协议**：中枢还在时，友方机器被摧毁 4 秒后在中枢身边**重新组装**(生命 50%；每台只能重构 1 次，召唤物不算)。中枢倒下 → 还没组装好的全部作废。
- 数值：攻 0(不攻击) / 防 30 / 魔抗 45 / 生命 2800 / 移速 0。
- 解法：先打中枢(它在最后面、不还手，但手下全都挂着链路)。

### RG-09 电磁轨道炮 `elite_rg_railgun`(炮台，不会移动)
三脚架上一根很长的电磁轨道炮管，两侧电容排，炮口一圈电弧。

- **蓄能射击【增幅 2/3】【吟唱 3】**：每 9 秒，锁定**离自己最远的敌人**，吟唱 3 秒(一道蓝色的锁定激光连着目标)，然后沿这条线发射贯穿弹：
  线上(宽 1.2 米、一直打到战场边)的**所有敌人**受到 攻击力 × 60% × 增幅 的物理伤害。被打断(眩晕 / 击退)就白充了。
- 平时的普攻：慢速的步枪(攻速 ×0.6)。
- 数值：攻 110 / 防 20 / 魔抗 25 / 生命 2000 / 移速 0。
- 解法：别排成一条线；切到后面打掉它，或者用控制打断蓄能。

精英的阵型：步行机 = 本体大、点数高(像虚荣)；中枢 / 轨道炮本体点数低、靠手下打(像忧郁 / 傲慢)。

## 3. 首领：OS-00 箱庭管理者 `boss_os_overseer`(人形仿生人，单挑)
城北信标里的管理者：高挑的仿生人女性，白色长发，白 + 藏青的装甲，背后悬着三道和信标一样的光环，手里一柄光刃长枪。

- **系统升级**：每 10 秒获得 1 层【系统升级】(最多 6 层)：被动增幅 +1 / 层——拖得越久，她的每个被动都越强。
- **格栅打击【增幅 2】**：每 5 秒，在 3 个随机敌人脚下展开一块格栅(半径 1.5 米)，1.5 秒后落下：格栅里的敌人受到 攻击力 × 25% × 增幅 的法术伤害。
- **全域清除【增幅 2】【吟唱 3】**：每 24 秒，举枪吟唱 3 秒(信标的光柱压下来)，然后对**所有敌人**造成 攻击力 × 40% × 增幅 的法术伤害。被打断就白唱了。
- 普攻：长枪(带长柄的贯穿)。数值：攻 130 / 防 50 / 魔抗 55 / 生命 8000 / 移速 2.0(首领倍率另算)。
- 节奏：第 24 秒的清除(增幅 2 + 2 = 4)= 攻击 × 160%，第 48 秒 = × 240%，第 72 秒 = × 320%……是一场限时的输出检测。追猎 = 2 星。

## 4. 事件

### 宵禁 `curfew`(限定：蓝之章，稀有度 1，带专属战场)
> 广播响起："现在是宵禁时间，请市民回到室内。"广场北边的安保探照塔亮了，一道白光一遍又一遍地扫过空无一人的广场。
> 这座城早就没有市民了，宵禁却还在照常执行。卡车停在广场边的阴影里。

| 选项 | 条件 | 结果 |
|---|---|---|
| 闯过广场。 | 无 | 事件战斗(专属战场**宵禁广场**，强度 = 节点 + 12、至少 26；赢了额外 2 个蓝色晶球) |
| 关掉车灯，等到天亮。 | 无 | 行动力 -2，趁机修车：卡车耐久 +12 |
| 黑进探照塔。 | 等级 ≥ 4 | 观测周围 4 格内的节点 + 4 经验 |

**专属战场「宵禁广场」**(`curfew_plaza`)：北侧正中是安保探照塔(3×3，高障碍)，敌人从它两侧出来；塔和我方部署区之间散着几块**掩体**
(广告立牌 / 全息亭 / 花坛立柱，高障碍)，卡车本身也挡光。
- 机制 `searchlight`：开战 5 秒后第一次、之后**每 11 秒**，探照灯从西向东扫过一个 150° 的扇面(2.5 秒，提前 2 秒塔顶红灯闪、警报)；
  光束照到、而且**和探照灯之间没有高障碍 / 卡车挡着**的单位(不分敌我)受到 **12% 最大生命 + 70** 的法术伤害并【过曝】3 秒(攻速 -30%)。
- 玩法：躲在掩体的影子里(部署时就看得到哪里是影子)；冲出去的近战、站在空地上的炮台都会被照到。画面上探照灯是一盏真的会投影子的聚光灯——影子就是安全区。

### 等门的家政机 `waiting_android`(限定：蓝之章，稀有度 2)
> 一扇半开的公寓门前，一台 HM-02 家政仿生人在扫门口的台阶。它看见卡车，鞠了一躬："欢迎回家。主人今天也会晚一点回来吗？"
> 门牌上的名字已经褪色了。

| 选项 | 条件 | 结果 |
|---|---|---|
| 陪它等一会儿。 | 行动力 ≥ 1 | 行动力 -1；它把"主人用不上的东西"装了一箱给你：一把 ≤ 3 费的武器 |
| 告诉它，主人不会回来了。 | 无 | 60%：它说"那我去照顾你们的车吧"——卡车耐久上限 +8、耐久 +15；40%：它安静地关机了，把核心电池留给你：液态负熵 +8 |
| 拆下它的核心。 | 无 | 液态负熵 +6、燃素 +2；附近的安保机器听见了：下一场战斗的敌人强度 +4 |

### 停摆的钟 `stopped_clock`(蓝色事件，稀有度 2：蓝 / 紫 / 青 / 黑之章)
> 路口的钟停在某个时刻，秒针一动不动。卡车开近的时候仪表盘上的数字也慢了下来——这里的时间像是被冻住了。

| 选项 | 条件 | 结果 |
|---|---|---|
| 把指针往前拨。 | 无 | 行动力 +2；时间在车身上流过去了：卡车耐久上限 -4 |
| 把指针往回拨。 | 无 | 下一场战斗的敌人慢了半拍：下一场战斗强度 -5 |
| 取下发条。 | 无 | 液态负熵 +5、+3 经验 |

## 5. 实现要点(新增的通用规则)

- 时机 `OnUnitDied` 给死者自己(殉爆)：目标规则 `nearby_units` 以死者的位置为圆心、`team any`(含队友)。
- 治疗目标：`all_allies` + 排序 `health_ratio_asc` + 条件 `has_hurt_ally`；数值模式 `attack_ratio_keyword`(终端，吃链路)。
- 状态链：过载 / 过热用状态参数 `burst`(到期发 `OnStatusBurst`)接力；过热 = flag `stun` + `damage_taken_pct -0.5`。
- 重构：新效果 `reassemble`(友方机器倒下 → `Battle.schedule` 4 秒后在中枢身边 `revive`；每台一次、中枢倒下作废、清掉晶球掉落标记)。
- 轨道炮：吟唱开始时锁定目标(`farthest`)，新目标规则 `rail_line`(从自己穿过锁定目标一直到战场边、宽 1.2 米的直线上的敌人)。
- 首领：`system_upgrade` = 叠层状态(每层 `passive_amplify_bonus` +1)；格栅 = 新效果 `grid_strike`(落点先画预警，1.5 秒后按落点结算)；
  清除 = 吟唱 + `all_enemies` + `all_targets`。
- 探照灯 = 新战场机制 `searchlight`(`Battle._step_searchlight`：扇面 + `BattleMap.has_los` 判影子)，伤害 / 过曝走 terrain.json(`terrain_searchlight`)。

## 6. 实现后的结果(2026-10-15)

- 全部按上面的设计实现(机制 / 数据 / 文本 / 模型 / 动作 / 特效 / 测试)，怪物的数值没有改，改的是强度点数和蓝之章的强度曲线。
- 强度点数(fit_power.py 标定，× 1.27 对齐红之章的刻度)：BX 2.5 / MR 3.3 / GW 12.2 / CN 9.0 / RG 11.2 / OS 25.4(首领用胜率曲线量，标定数据里参考阵容全胜)。
- 蓝之章的强度曲线比红之章高一点(圆形大地图多走 5 个节点，队伍更强)：普通作战上限 40、精英 +20、强怪 +6~10、首领 45、追猎 58。
- campaign_bench(60 局)：通关 90%，普通 99% / 强怪 96% / 精英 65~81% / 首领每次 49%(同版本的红之章：98 / 87 / 66 / 56%，通关 96%)。
- 宵禁的事件战斗：+6 / 至少 20 时 24 场全胜(探照灯也照机器)，改成 +12 / 至少 26。
- 细节见 `docs/GAME_DESIGN.md` 的「第一章-B：蓝之章」一节。

## 7. 战斗地形：供能地砖(2026-10-15)

蓝之章的战斗地图(`MapGen` 主题 `blue`)在科技障碍之外加一种**地形效果**：箱庭还在给早就没人用的机器人供电——
广场上一块块嵌在地面里的**无线供能地砖**，电一直在充。

### 规则(玩家看到的)

| 项目 | 内容 |
|---|---|
| 形态 | 地面上发光的六边形地砖，1×1 / 2×1 / 2×2；**不占格、不挡路**，不会消失(只有裂地猛击能砸碎) |
| 满电 | 开战时每块都是满的(亮着青光、往上冒光点) |
| 吸电 | 棋子(**敌我都算**)踩上满电的地砖 → 把电一次吸走，获得【满电】6 秒：**攻击速度 +25%、计时加速 +25%(“每 x 秒”的效果 / 冷却走得更快)、被动技能的【增幅】+1**；再吸一次 = 刷新时间(不叠加) |
| 充电 | 吸空的地砖暗下去，边上一圈 8 格刻度一格一格亮起来，**8 秒后重新充满**(满了闪一下)；充满的那一刻有人站在上面 → 立刻被他吸走(离地砖中心最近的那个) |

一句话：**地砖是一个 8 秒的计时器，谁站在上面谁“满电”。**一直站在地砖上 = 每 8 秒里有 6 秒满电；路过的人只吸一次。

### 和蓝之章的两个原语怎么挂钩

- **【增幅】**：满电给被动 +1 增幅——蓝之章的每一台机器都靠【增幅】(炮台火控 2 → 3 = 伤害 +50%，殉爆 / 维修 / 震荡锤 / 格栅都一样)，
  我方带【增幅】的节点(架盾 / 舞星 / 和星 / 巫术 / 奇兴)也吃得到。
- **每 x 秒的计时器**：地砖本身就是一个看得见的 8 秒倒计时；满电的计时加速让“每 x 秒”的效果更快——中继的广播 4 秒 → 3.2 秒，
  中枢 / 维修 / 轨道炮 / 首领的格栅和清除也一样；我方蓝色节点的计时器同理。

### 摆位怎么利用

1. **开局抢电**：地砖离部署区至少隔 1 格(和寒雾一样)，离部署区近的那几块我方先到——开局 6 秒的满电是白给的；离敌人出生点近的归敌人。
   部署时就看得到地砖在哪(备战时悬停有提示)，把近战 / 快的棋子放在靠地砖的那一边。
2. **站桩**：远程站在地砖上开火 = 75% 的时间满电。卡车改装“部署区跟着卡车走”能把部署区挪到地砖上，直接把远程摆在地砖上。
3. **别让机器站上去 / 先把电吸掉**：机器踩上去更疼(增幅 +1、计时更快)；不会动的炮台 / 中枢 / 轨道炮如果刚好站在地砖上，就是一台一直满电的机器——
   先集火它，或者派人把那块的电吸走(吸空的 8 秒里谁也拿不到)。
4. **首领**：管理者踩上地砖 = 计时加速让格栅、系统升级、全域清除都来得更快、增幅再 +1——别在地砖上和她打；地砖在她的路上就先派人吸空。

战斗 AI 不会主动去找地砖(和别的地形一样，只靠摆位影响)。

### 数量与实现

- 数量(`tools/author_chapters.py` 的 `CH1_BLUE.battle_map`，键 `pads`)：作战 3、精英 3、首领 4、追猎 4。
- 逻辑：`BattleMap.pads`(`{id, rect, style, charged, ready_at}`，`pad_under` 判踩没踩着)；`Battle._step_pads` 每一步：
  充满的地砖上有棋子 → 吸空(`ready_at = 时间 + 8`)，发 `OnTerrainEnter[power_tile]`；到点充满 → 表现事件 `pad_ready`。
- 效果走 `terrain.json` 的“触发器 + 能力”：`terrain_power_tile`(`OnTerrainEnter`，`event_has_tag power_tile`) → 状态 `supercharged`
  (【满电】，增益、可驱散、没有施加者)。
- 表现：`BattlefieldView.pad_node`(六边形地砖贴花：满电 = 青色 + 光点，空 = 暗 + 一圈 8 格的充电刻度，跟着逻辑层的 `ready_at` 走)；
  吸电 = 地砖往棋子身上连一道数据光(`Fx.data_link`) + 青色的闪光；充满 = 一圈光环。备战时悬停有提示(`ui.terrain.pad`)。
