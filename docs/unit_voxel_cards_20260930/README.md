# 体素多视角分拆角色卡

用途：为 D:\voxel 的自走棋游戏制作角色建模参考图。

## 覆盖范围

源目录：G:\auto_battler\auto_battler\rebuild_auto_battler\assets\units

已完成 46 张 PNG：44 个正式单位原画，以及 archer_idle_0、darkknight_idle_0 两个旧版动画帧变体。排除名称含 _battle 的素材和 Godot .import 文件。文件名与源素材一一对应，详见 manifest.json。

## 浏览与使用

- 打开 index.html：本地图库，可按单位文件名搜索，点击卡片查看原尺寸。
- cards/：每个单位一张独立多视角 PNG。
- prompts/：每张图实际提交给内置 image_gen 的完整提示词。
- manifest.json：原图路径、SHA-256、类别、输出路径、实际像素尺寸与输出校验值。

每张卡的结构为：左上完整角色主视图；右上独立装备、衣装或组件；左下正面、背面、侧面转面；右下三处局部特写。动物、灵体、工程石、水镜等单位按自身形体处理。

## 风格来源

用户提供的白发弓手角色卡作为最初版式参考。D:\voxel\docs\character_sheet.png、D:\voxel\out\final_archer.png、final_dancer.png、final_nurse.png 作为现有游戏模型参考：Q 版比例、可见立方体颗粒、阶梯轮廓、平面像素眼睛、分层发束与可读装备结构。

archer_voxel_card.png 是本批首张统一版式参考，其他单位沿用其分区和展示方式。所有角色保留各自源图的发色、种族、服装、主色和标志装备；没有将其他角色替换成白发弓手。

## 生成与建模说明

整批均由 Codex 内置 image_gen 绘图工具逐单位生成，未调用外部 API/CLI 绘图。PNG 保留工具原始输出尺寸，不做放大伪造细节。

这是图像建模参考，非可直接导入的 .vox 或三维网格。单张原画未展示的背面、装备内侧和连接方式按源设计补全；落地模型时应统一体素网格、关节位置、碰撞与绑定要求。

本批交付独立参考图，不替换源单位原画，不改动游戏脚本、模型资源或已构建的可执行文件。

46 张均已逐张目视检查并成功解码，实际分辨率为 1122 × 1402 像素。46 张输出各不重复，46 份提示词齐全；源目录全部非 _battle PNG 已覆盖，源文件 SHA-256 保持不变。核验记录见 verification.json。
